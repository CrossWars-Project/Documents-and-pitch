# Welcome to CrossWars

If you are a developer contributing to this project, this is the place to be.

This guide provides two essential documents for getting started with CrossWars development. Read them in order for the best experience.

---

## 1. Setup (First-Time Only)

**[setup.md](setup.md)** - Complete this guide once when joining the project:
- Repository access and source code setup
- Installing required tools (Python, Node.js, Git)
- Creating virtual environments
- Installing dependencies
- Configuring environment variables and API keys
- Directory structure overview

**Start here if:** You're new to the project or setting up a new development machine.

---

## 2. Contributing (Daily Development)

**[contributing.md](contributing.md)** - Use this guide for all development work:
- Building and running the application (backend + frontend)
- Testing the software (backend + frontend)
- Adding new tests (naming conventions, structure, examples)
- Development workflow (branching, commits, pull requests)
- Building releases (version updates, deployment, sanity checks)
- Troubleshooting common issues

**Use this when:** You're ready to code, test features, or prepare a release.
